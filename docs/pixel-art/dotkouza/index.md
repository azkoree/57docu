# 像素画讲座  ドット絵講座

多年前RPG Maker官方出的一个游戏用像素画教程系列，应该还是rm2000的时代，在硬件和软件方面可能有些过时了，但是对像素画的理解还是能跟得上现代的。所以这里进行一个存档，防止它变成lostmedia。

网上可以搜到一个gitbook版本，但那个年久失修，很多图片加载不出来（包括我这里的存档也有一些图片丢失），所以这里试着进行一个机翻+人力润色



这次无法附上原文链接了，因为已经被收入互联网档案馆力（悲），最后一次存档应该是在2007年
