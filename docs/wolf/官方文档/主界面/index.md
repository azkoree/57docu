# 主窗口

![img](https://silversecond.com/WolfRPGEditor/Help/MainWindow.png)

## 各部分说明

1：创建新地图/保存按钮

2：选择地图编辑图层（1-3）和事件编辑图层（Ev），按下1-3时，会显示地图元件窗口

3：选择地图的显示倍率

4：创建地图时可以使用的绘图工具，分别为铅笔、填充、举行填充、地图自动生成、撤回一步

5：打开各种数据库的按钮，为蓝：用户数据库、黄：变量数据库，红：系统数据库

6：与地图相关的特殊工具，分别为图块编辑器、地图首选项、公共事件、地图选择工具

7：开始游戏测试，测试时可以按F8查看加载的文件和使用的图片，F9查看变量

8：编辑地图。通过放置元件来绘制地图

## 操作方法

- 在2中选择第一层~第三层时：
  - **左键单击**：在指定的方格上画一个元件
  - **右键单击**：使用吸管（复制）通过拖动来复制范围内的元件布局
  - **Ctrl+右键单击**：批量复制，拖动即可获取范围内所有层1到层3的元件布局，然后Ctrl+左键单击进行粘贴
  - **Ctrl+左键单击**：见上
  - **Shift+左键单击**：绘制一个禁用自动元件功能（例如衔接草和水边）的元件
  - **Ctrl+Z**：在地图编辑中执行撤回
- 选择事件层[Ev]时
  - **左键单击**：选择事件
  - **左键双击**：创建/编辑事件
  - **右键单击**：打开子菜单
- 两者共通：
  - **拖动中键、空格键+移动鼠标**：滚动地图屏幕
  - **Ctrl+Shift+方向键**：向指定方向整体移动地图一格
- 快捷键：
  - **1~4**：更改使用的图层
  - **Ctrl+S**：保存地图
  - **Ctrl+鼠标滚轮**：改变放大倍率
  - 编辑事件层：
    - **X**：剪切
    - **C**：复制
    - **V**：粘贴
    - **delete或backspace**：删除事件
  - 编辑地图时：
    - **Q**：铅笔工具
    - **W**：填充工具
    - **E**：矩形填充工具
    - **X**：橡皮擦

## 地图元件窗口

按下1-3图层选择按钮时，将自动显示该窗口。

通过左键单击选择要使用的元件，并在主界面的地图上绘制。也可以通过拖动来一次性选择多个元件。选择单个元件时，会显示元件编号、元件标签编号和通行设定

**拖动中间按钮**：滚动地图元件窗口
