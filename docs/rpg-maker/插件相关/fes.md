# 范例工程：Tkool Face

Fes死了，但它的精神将永远延续下去（大嘘

RPG Maker Fes是曾经在3DS发行的RM系列产品，现在和3DS一起殉了。它本身的UI挺不错很有特点，也有一些独有的功能。

于是就有了作者あわや制作的，在MZ上几乎一比一复刻FES功能特点和UI的范例工程，原文和下载链接如下（下载链接是谷歌盘，自己想办法吧）

[ツクールFACE【サンプルプロジェクト】: あわや自己またもや三時](https://awaya3ji.seesaa.net/article/498823510.html#agenda-u0tph2__1-2)

里面包含了很多插件，即使不打算做fes风格的游戏，也可以单独拿出来用，有不少比较实用的功能。搬一些原站点的截图：
