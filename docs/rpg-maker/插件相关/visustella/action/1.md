## 前言

首先动作序列并非是完全用来在侧视战斗做特效的，实际上尽管在正视图战斗中也可以用来做**战斗机制**，因为动作序列是用公共事件写的，所以可以利用事件来实现你想要的效果（包括判断敌人或角色状态等等）



## 说明

### 基本的设置

在数据库创建一个基本的火焰技能“Enflame”，效果是对敌方单体造成伤害。

在备注栏输入`<Custom Action Sequence>`，就可以启用动作序列了

![ActSeqTut1 Image1.png](http://www.yanfly.moe/wiki/images/thumb/7/72/ActSeqTut1_Image1.png/600px-ActSeqTut1_Image1.png)

然后在公共事件里创建一个新的公共事件，命名为“Enflame”，在这个公共事件里面开始加入动作序列指令。

![ActSeqTut1 Image2.png](http://www.yanfly.moe/wiki/images/thumb/7/70/ActSeqTut1_Image2.png/600px-ActSeqTut1_Image2.png)

动作序列是通过Battle Core的插件指令来实现的，可以看到有相当多的指令，不过我们实际用到的也就那么几个（因为很多都是付费插件才能用的选项）

![ActSeqTut1 Image5.png](http://www.yanfly.moe/wiki/images/thumb/2/2b/ActSeqTut1_Image5.png/400px-ActSeqTut1_Image5.png)

![ActSeqTut1 Image6.png](http://www.yanfly.moe/wiki/images/thumb/b/b8/ActSeqTut1_Image6.png/400px-ActSeqTut1_Image6.png)

首先选择Setep Action Set，作为动作序列的开始。对于参数设置，我们用正视图战斗所以把Battle Step关了，其他的照着图或者自己看情况设置就行了

![ActSeqTut1 Image8.png](http://www.yanfly.moe/wiki/images/thumb/e/ec/ActSeqTut1_Image8.png/600px-ActSeqTut1_Image8.png)

然后再添加一个插件指令，这是Action Animation，就是释放技能时播放的动画，可以选择等待动画播放完毕或者镜像播放，随意

![ActSeqTut1 Image9.png](http://www.yanfly.moe/wiki/images/thumb/3/32/ActSeqTut1_Image9.png/300px-ActSeqTut1_Image9.png)

![ActSeqTut1 Image10.png](http://www.yanfly.moe/wiki/images/thumb/a/ad/ActSeqTut1_Image10.png/600px-ActSeqTut1_Image10.png)

然后再添加一个插件指令，Action Effect，就是实现技能的效果（造成伤害或者治疗等等），如果没有这个指令，技能就不会真正生效

![ActSeqTut1 Image11.png](http://www.yanfly.moe/wiki/images/thumb/c/c5/ActSeqTut1_Image11.png/300px-ActSeqTut1_Image11.png)

![ActSeqTut1 Image12.png](http://www.yanfly.moe/wiki/images/thumb/1/1a/ActSeqTut1_Image12.png/600px-ActSeqTut1_Image12.png)

最后添加Finish Action，这个指令就是来结束动作序列，让战斗继续进行下去。

![ActSeqTut1 Image12a.png](http://www.yanfly.moe/wiki/images/thumb/f/f2/ActSeqTut1_Image12a.png/300px-ActSeqTut1_Image12a.png)

![ActSeqTut1 Image13.png](http://www.yanfly.moe/wiki/images/thumb/4/42/ActSeqTut1_Image13.png/600px-ActSeqTut1_Image13.png)



### 测试技能

回到技能设置窗口，将刚才设置的公共事件加入技能，就可以在战斗中看到技能的效果了

不过这和数据库设置的技能又没什么区别了，所以接下来玩一点花样



### 自定义

创建一个新技能，名为“Flame Aura“，目标设置为使用者，启用动作序列

![ActSeqTut1 Image16.png](http://www.yanfly.moe/wiki/images/thumb/5/5a/ActSeqTut1_Image16.png/600px-ActSeqTut1_Image16.png)

然后设置一个同名的状态，也叫Flame Aura，持续三回合，可以获得25%攻击和5%HP恢复的提升，是一个己方增益，然后回到技能设置，让刚才的技能可以附加这个状态

![ActSeqTut1 Image17.png](http://www.yanfly.moe/wiki/images/thumb/6/60/ActSeqTut1_Image17.png/600px-ActSeqTut1_Image17.png)

![ActSeqTut1 Image18.png](http://www.yanfly.moe/wiki/images/thumb/7/7e/ActSeqTut1_Image18.png/600px-ActSeqTut1_Image18.png)

进入公共事件开始设置动作序列，可以直接copy一个我们刚才创建的动作序列作为模板，然后改名来方便记忆

![ActSeqTut1 Image19.png](http://www.yanfly.moe/wiki/images/thumb/8/8e/ActSeqTut1_Image19.png/600px-ActSeqTut1_Image19.png)

现在Flame Aura这个技能还没在动作序列里整什么花样，不过先把公共事件加入技能中，看一下技能释放应该没什么问题

![ActSeqTut1 Image20.png](http://www.yanfly.moe/wiki/images/thumb/e/ed/ActSeqTut1_Image20.png/600px-ActSeqTut1_Image20.png)

![ActSeqTut1 Image21.png](http://www.yanfly.moe/wiki/images/thumb/5/54/ActSeqTut1_Image21.png/600px-ActSeqTut1_Image21.png)

确实没什么问题

然后回到先前的Enflame公共事件中，在事件中创建一个条件分歧，判定角色是否具有Flame Aura这一状态，注意勾选下面除此以外的场合

![ActSeqTut1 Image22.png](http://www.yanfly.moe/wiki/images/thumb/d/d3/ActSeqTut1_Image22.png/400px-ActSeqTut1_Image22.png)

大概是在这么个位置

![ActSeqTut1 Image23.png](http://www.yanfly.moe/wiki/images/thumb/a/a1/ActSeqTut1_Image23.png/600px-ActSeqTut1_Image23.png)

然后把Action Animation和Action Effect挪到除此以外的场合里面

![ActSeqTut1 Image24.png](http://www.yanfly.moe/wiki/images/thumb/6/6b/ActSeqTut1_Image24.png/600px-ActSeqTut1_Image24.png)

然后再复制一份到条件分歧里面，也就是这一状态存在的时候。将”释放目标（Current Target）”设置为“存活的敌方”

![ActSeqTut1 Image25.png](http://www.yanfly.moe/wiki/images/thumb/e/e5/ActSeqTut1_Image25.png/600px-ActSeqTut1_Image25.png)

进入战斗测试，可以看到现在的效果就是：直接使用Enflame只会攻击单体，但如果拥有Flame Aura再使用Enflame，就会对敌方全体造成伤害

![ActSeqTut1 Image27.png](http://www.yanfly.moe/wiki/images/thumb/d/d6/ActSeqTut1_Image27.png/600px-ActSeqTut1_Image27.png)

那么这就是比较基本的动作序列的用法了
