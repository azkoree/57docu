# Elements and Status Menu Core



[Elements and Status Menu Core VisuStella MZ - Yanfly.moe Wiki](http://www.yanfly.moe/wiki/Elements_and_Status_Menu_Core_VisuStella_MZ)




## 简介

元素与状态菜单核心插件让您能够更精细地控制游戏内的元素属性值计算，提供特性集来简化为角色和敌人分配元素的操作，并更新状态菜单以正确显示所有相关信息。

功能包括（但不限于）以下内容：
- 可从目标和玩家端控制元素属性值。
- 新增元素吸收和元素反射机制。
- 可为物品和技能分配多元素属性。
- 可通过加法和乘法标记调整元素属性值。
- 强制元素属性值并禁用元素属性。
- 新增特性集，可通过标记批量分配特性。
- 特性集可用于分配元素、子元素、性别、种族、天性、阵营、祝福、诅咒、星座和变体。
- 随机特性集，带有权重，使敌人更具动态性。
- 可通过插件命令在游戏过程中更改角色特性。
- 更新了状态菜单布局，以显示所有新信息。
- 可控制状态菜单中的信息类别标签。
- 可通过插件命令在游戏过程中更改角色小传。



## 主要改动

此插件为 RPG Maker MZ 的函数添加了一些新的硬编码功能。以下是这些功能的列表。

---

### 元素伤害计算

[![Elements.png](http://www.yanfly.moe/wiki/images/3/39/Elements.png)](http://www.yanfly.moe/wiki/File:Elements.png)

在 RPG Maker MZ 中，元素伤害的计算方式非常具体：获取目标在各种数据库对象中查找的元素抗性，并将伤害值应用到该抗性值上。此插件扩展了这一计算方式，提供了更多方法来扩展目标的元素伤害率，并添加了一个属性，该属性引入了攻击者的元素加成伤害。

---

### 多元素伤害计算

在 RPG Maker MZ 中，默认情况下，如果一个动作被赋予了多个元素，则采用伤害率最高的元素。此插件将让游戏开发者决定如何处理此问题：默认最大速率、最小速率、乘法运算、加法运算或所有计算出的元素速率的平均值。
