# 事件昼夜+天候系统

自己想做生存游戏？类似生存游戏这类自由度较高的游戏通常会有昼夜循环系统，自己是否也想做一个？通过此教程你可以学到如何让游戏有昼夜和天气的变化，同时室内与室外同一时间段的光影也是完全不同的哟~

范例预设：

一共八个时间段，分为凌晨，朝晨，上午，正午，下午，黄昏，夜晚，午夜。

一共五种天气变化，分为晴朗，小雨，暴雨，多云，雾。
室内与室外在同一条件下会有不同的光影表现，具体表现为：

1. 室内通常比室外的光照暗一些。
2. 室内会在夜晚时间段开灯。
3. 晴朗天气时，除非是在晚上，室内的窗户会透光。
4. 雷雨天气时，室内的窗户在打雷时会闪光。此外，为了程序的可控性，我将天气的变化设置为每个时间段最多只变化一次。

该系统是我第一次做，此版本在优化方面或许还有进步空间，若有高人有更好的算法点子欢迎进一步拓展该系统。

## 要点

难度并不算高，注意调节好光效细节。除此之外，若存在室内和室外的地图则要特别留意室内外的光影区别。

## 开始

打开范例工程中数据库-公共事件，左方列表一直往下翻，找到“天气控制台”，那么往下的5个公共事件就都是关于此系统的了。

看上去数量似乎有点多，放心，其中只有两个是并行处理的，剩下的三个只是方便制作者制作，区分开主控制台，但会在主控制台内被调用。

咱先看到“主控制台”的公共事件，里面是对各种情况的判断，虽然看起来多，其实整列下来只需要基于两三种运算方法就行了。
翻到事件中部，找到这个注释。

![img](https://img.57hmpg.top/file/1771579326221_192806jxn4ejuwyzo1v244.png)

这个注释是区分室内外的，也就是说，从这里开始，上方的事件为室内，下方为室外，注意分清了。

再返回来第一行开始看。

![img](https://img.57hmpg.top/file/1771579333343_192806pww6rfvikocjkizn.png)

注释：

①变量操作：这里是时间段的控制，时间推移的时候记得要将这个变量+1。如果你发现游戏中无论怎么傻等都等不到天气变化的话，不要找我，是时辰的错。

②分歧清零变量：先说说系统的时间段，一共八个时段，那么变量0-7分别代表每个时间段，也就是说不可能存在8的时间，所以当变量加到8的时候需要清零。

③变量操作：此随机数用来做随机天气的抽签。

④条件分歧：这个分歧很重要，用来判断玩家是否在室内的，如果是则往下执行，否则就执行刚刚那个注释以下的部分。开关的操作通常在场所移动后控制。

⑤公共事件：用于给随机数做判断，确定天气类型。

⑥开关操作：这个开关是室内独有的开关。记得游戏中如果到了晚上的话，呆在室内会开灯么？灯的表现效果就是由这个开关控制的。除此之外，室外的天气系统也有一个“路灯”的开关，同样原理，只不过是用来控制路灯的。

⑦条件分歧：进行天气判断。会根据不同的天气进行不同的色调变化，以及音效变化。

⑧移动图片：这个是用来控制例如阳光这类的光效图片的，你可以根据光照强度调整图片的不透明度。

于是主控制台的运行原理都是基于以上运行的，但目前还不能表现效果。为啥呢？因为天气的开关全都没打开！

接下来要做的事将对应的天气开关打开，看到左边的公共事件列表，找到“朝晨天气控制台”和“非朝晨天气控制台”两个公共事件。也许你会问，这俩有啥区别。还记得有个“雾”的天气么？雾只会在朝晨时间出现，如果不是这个时间段的话就取消这个判断了。

![img](https://img.57hmpg.top/file/1771579366652_203406iwhlwbh55jq2sjea.png)

注释：

①条件分歧：用来判断是否在室内。ON为室内。

②条件分歧：如果是暴雨天气就隐藏阳光。

③条件分歧：天气的随机范围，也就是触发天气的概率，这个可以自己设定，那么剩下的就是将开关打开了。

天气的判断完成了，做到此处的话，系统就完成了大半了，剩下的就是室内外切换时光效的变化和暴雨的打雷表现。

先从简单的做起，公共事件列表处继续往下翻，找到“雷电控制”。

里面的事件应该简单明了，区分为室内（只有雷声）和室外（带上画面闪烁），不用多做解释吧？

那么接下来找到“室内外切换天气”。

![img](https://img.57hmpg.top/file/1771579559649_204625qg7l3ga1j93gr77o.png)

注释：

①开关操作：关上

②开关操作：嗯，连着上面那个一起讲。算了还是下面再讲吧。

![img](https://img.57hmpg.top/file/1771579573787_204625l3vobsqp9nbjsn3b.png)

注释：

①开关操作：记得切换后打开或关闭对应的开关。

②暴雨特殊控制事件：嗯我真的开始讲了。这个真的有点意思，在写这个系统的时候我也被蒙了好一会儿。具体问题是：雷雨天气时从室外回到室内后打雷依然会画面闪烁，这是因为“雷电控制”为并行处理，需要处理完一轮回来再重新判断是否在室内。把开关关掉让它先停止运作，等切换完毕之后再将开关打开来解决这个问题。
