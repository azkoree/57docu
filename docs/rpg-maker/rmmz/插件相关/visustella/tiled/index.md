# Tiled MZ 插件

支持在RPG Maker MZ中使用Tiled绘制的插件，比较适合我这种不爱用ulds（只是个人习惯对这个插件没有意见）又觉得编辑器画地图太单调的人

需要用到[Tiled | Flexible level editor](https://www.mapeditor.org/)这个免费开源软件，这里不会赘述这个软件的用法，请自行摸索

参照范例工程中的文本进行撰写，不懂还是建议去范例工程看看
