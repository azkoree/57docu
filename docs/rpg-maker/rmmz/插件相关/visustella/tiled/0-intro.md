# 快速入门

省流：看不懂就去看范例工程怎么做的



## 需求

这个插件需要一些前置插件

- 本插件（VisuMZ_5_TileZ.js）
- Public_0_PixiJSFilters.js，这个要排到上面
- TileD程序

插件安装懂得都懂，就不多说了

## 配置

1. 为地图和素材准备一个文件夹
2. 制作和放入在TileD使用的图块
3. 制作新地图
4. 在地图中进行开发（设置事件）

### 文件夹

首先确保安装好并开启了两个插件，注意插件顺序

在工程文件夹中新建一个文件夹，可以取名为maps，这里面包含TileD地图和图块集数据。可以在这个文件夹里再建一个文件夹（比如取名为Tilesets）来放图块集数据，把地图和图块集分开

### 使用图块集

Tiled使用的图块集包括两个部分：图块集图片和json数据，这两个文件都是必须的

图片文件和通常情况一样放在img/Tilesets中，json数据（在Tiled中创建并保存）要放在上面新建的那个新文件夹中，比如maps/tilesets。

我们需要的图块集，除了通常用来画地图的普通图块之外，还需要一个系统图块集，用来设置通行等等的，可以直接用范例工程里准备的

### 绘制新地图

在编辑器中新建好地图后，在maps文件夹里也需要有一个保存地图数据的json文件，同时两个地图的名称必须要对应好，json文件要取名为对应地图的id，比如22号地图，json文件就要命名为map22.json

这个json文件是在Tiled中画好后导出的，它可以导出tmx和tsj文件，但是这个插件只认json，导出tsj后直接改后缀名就行

### 设置事件

然后在编辑器里直接设置事件就行（也能直接在TileD中进行设置，后面再讲），不过编辑器里没法直接看到我们画的地图，可以直接导出png设置远景图



**总结**：需要一个名为maps的文件夹，包含Tiled导出的地图和图块集数据，地图json的文件名要和地图id对应，格式为map(id).json

## TileD操作

Tiled可以为地图制作多个新图层，这个插件支持使用和识别图层组

同时需要为图层给定特定的**属性**（Properties），来让MZ来识别图层的功能，是重中之重，图层和图层组必须要设置至少一个属性。对于在Tiled设置属性的方法这里不赘述了

每个属性包括三个要素：属性名、属性类型和属性值，这里会涉及到的属性类型分为：

- 文本：属性值为字符串
- 数值：属性值为数字
- 布尔值：属性值为true或false，勾选框

如果类型设置错，可以右键修改

## 注意事项

用了这个插件，编辑器的地图绘制功能就失效了

此外，TileD对图块集的规格没有什么要求但还是要把图片大小限制在1024x1024之间

**注意！TileD读的是相对路径，如果随便乱动json文件或者图片文件，就有可能无法读取，所以尽可能整理好文件夹结构**
