# 基础使用

本部分会粗略介绍一下使用TileD制作地图的方法

## zIndex - INT

这是相当重量级的属性，就是那个，在角色下方、与角色同层和在角色上层

注意这个属性是数值类型（后面属性类型都会标在小标题上），不同的值对应不同的优先级：

- 1：在角色下方
- 3：与角色同层
- 4：在角色上方

这个属性可以用在图层组，来批量设置各个图层的优先级

## priority - INT

zIndex是判断角色和地图的层级，那么这个就是在游戏中显示各个图层的顺序

这个属性应该附加到图层上，可以按这个例子来设置：

- zIndex 1：priority 1 2 3 4
- zIndex 3：priority 1 2 3 4

不设置属性，就会按TileD中的图层顺序来显示，不过最好还是设置好priority属性
