# Options Core 

[Options Core VisuStella MZ - Yanfly.moe Wiki](http://www.yanfly.moe/wiki/Options_Core_VisuStella_MZ)



## 简介

Options Core 插件对 RPG Maker MZ 中的选项菜单场景进行了全面升级，使其功能更加丰富，并支持更多种类的选项。除了其他 VisuStella MZ 插件（前提是这些插件也已安装）提供的选项外，该插件还会向菜单中添加新的选项。精通 JavaScript 的游戏开发者也可以向菜单中添加自定义选项。

功能包括（但不限于）以下内容：

- 重新设计的选项菜单场景和布局。
- 允许在每个类别中添加自定义类别和选项。
- 新增了主音量、窗口音调等选项。
- 集成了其他 VisuStella MZ 插件的选项。
- 新增了仅在测试模式下可用的“游戏测试”选项类别，以帮助加快游戏调试过程。


## 主要变更

此插件为 RPG Maker MZ 的功能添加了一些新的硬编码特性。以下是这些特性的列表。

---

### 选项菜单场景

[![OptionsCoreTab2.png](http://www.yanfly.moe/wiki/images/thumb/d/d7/OptionsCoreTab2.png/600px-OptionsCoreTab2.png)](http://www.yanfly.moe/wiki/File:OptionsCoreTab2.png)

由于 Options Core 插件提供的所有新增功能，整个场景都进行了重新设计。虽然基本功能仍然有效，但请不要期望所有功能都能完美集成。

---

## 额外功能

如果在插件管理器列表中找到其他 VisuStella MZ 插件，则会显示一些额外功能。这些插件大多为 Options Core 提供了新的功能选项，因为实现这些功能的代码位于较新的插件中。

---

### 许多 VisuMZ 插件

这些插件都包含一些选项，当与 Options Core 插件一起安装时，这些选项即可使用。
