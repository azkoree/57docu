# Main Menu Core 


[Main Menu Core VisuStella MZ - Yanfly.moe Wiki](http://www.yanfly.moe/wiki/Main_Menu_Core_VisuStella_MZ#Introduction)


## 简介

主菜单核心插件旨在让您在 RPG Maker MZ 编辑器之外，对主菜单拥有更多控制权。游戏开发者可以控制命令的运作方式、主菜单的视觉效果，以及将菜单图像分配给角色作为背景头像。

功能包括（但不限于）以下所有方面：
- 控制主菜单的常规设置。
- 为单个角色设置菜单背景头像。
- 灵活更改主菜单中显示的命令。
- 添加新的窗口，例如游戏时间窗口和变量窗口。
- 更改主菜单中窗口的排列方式。
- 更改状态列表的显示方式。
