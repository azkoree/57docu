# 自定义技能消耗

[Custom Skill Cost System](http://www.yanfly.moe/wiki/Custom_Skill_Cost_System)

## 前言

这篇就是系列教程的最后一篇了

这回要做一个自制的技能消耗系统，而且要用到图片、变量和一些JS函数

这次的目标有二：

- 自定义并实现一个在战斗中显示的技能条
- 创建一个使用该技能条的技能



## 制作技能条

现在初始化完成，接下来如何将它用在战斗中呢？

首先要让图片显示在战斗中。可以通过Battle Core插件的插件参数来一次性设置，就不用单独在每个敌群事件中设置一遍了

把它设置为1或者随便几号都行。然后去1号敌群事件调用初始化事件，然后技能条就会显示在战斗中了

## 制作技能

现在技能条已经ok了，开始制作一个使用这个技能条的技能

这次的新技能叫Impulse Slash，它比较强，敌人被烧伤时还会造成额外伤害

先进行必要的设置，然后启用Battle Core中的JS函数，将下面的代码输入备注栏中

```
<JS Skill Enable>
enabled = $gameVariables.value(4) >= 4;
</JS Skill Enable>
```

意思就是这个技能在4号变量大于等于4之前无法使用，也就是要技能条满了才能用

然后再加入如下自定义消耗文本

```
<Custom Cost Text>
\C[2]100% Burst
</Custom Cost Text>
```

这会在菜单中标记该技能消耗100%技能条，且文本颜色为2（默认来讲，也就是红色）

![MirageV ActSeqTut4 13.png](http://www.yanfly.moe/wiki/images/thumb/8/82/MirageV_ActSeqTut4_13.png/600px-MirageV_ActSeqTut4_13.png)

老样子，做动作序列，这次再加一点简单的演出

给这个技能加个闪光和震动效果，然后根据敌方是否存在烧伤状态来造成额外效果，只要添加图片和音效就行

![MirageV ActSeqTut4 14.png](http://www.yanfly.moe/wiki/images/thumb/1/1f/MirageV_ActSeqTut4_14.png/600px-MirageV_ActSeqTut4_14.png)

![MirageV ActSeqTut4 15.png](http://www.yanfly.moe/wiki/images/thumb/c/c9/MirageV_ActSeqTut4_15.png/600px-MirageV_ActSeqTut4_15.png)

然后进行条件分歧判断是否有烧伤状态，通过`BattleManager._target.isStateAffected(X). X`来进行判断（X填入烧伤状态的编号），这用于判断目标是否受烧伤状态的影响

![MirageV ActSeqTut4 16.png](http://www.yanfly.moe/wiki/images/thumb/2/26/MirageV_ActSeqTut4_16.png/400px-MirageV_ActSeqTut4_16.png)

然后加入额外效果，包括新的动画、伤害倍率以及额外的技能效果

![MirageV ActSeqTut4 17.png](http://www.yanfly.moe/wiki/images/thumb/0/04/MirageV_ActSeqTut4_17.png/600px-MirageV_ActSeqTut4_17.png)

然后将技能条清零，并调用图像管理器

![MirageV ActSeqTut4 18.png](http://www.yanfly.moe/wiki/images/thumb/e/eb/MirageV_ActSeqTut4_18.png/600px-MirageV_ActSeqTut4_18.png)

现在开始测试，这是没有烧伤的时候

![MirageV ActSeqTut4 19.png](http://www.yanfly.moe/wiki/images/thumb/5/5e/MirageV_ActSeqTut4_19.png/600px-MirageV_ActSeqTut4_19.png)

然后现在又烧伤状态

![MirageV ActSeqTut4 20.png](http://www.yanfly.moe/wiki/images/thumb/4/43/MirageV_ActSeqTut4_20.png/600px-MirageV_ActSeqTut4_20.png)

很好，现在启动了二阶段攻击，造成了更大的伤害
