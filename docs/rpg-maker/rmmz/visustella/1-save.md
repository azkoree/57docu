# Save Core 

[Save Core VisuStella MZ - Yanfly.moe Wiki](http://www.yanfly.moe/wiki/Save_Core_VisuStella_MZ#Introduction)


## 简介

Save Core 插件增强了 RPG Maker MZ 中现有的存档功能，并改进了游戏内存档菜单的显示方式。该插件还提供了对自动存档的控制，以及在所有游戏存档（包括新游戏）中启用全局开关和变量的功能。

功能包括（但不限于）以下内容：
- 存档文件技术细节，例如文件名生成方式和/或用于区分不同游戏的采集钥匙标签。
- 存档类型（标准、槽位锁定或单次），可根据不同游戏类型调整存档方式。
- 新增存档确认窗口，向玩家显示存档是否成功。
- 全局开关和变量，可应用于所有存档和新游戏。
- 控制自动存档的处理方式（保存到新文件、覆盖现有文件或两者兼有）。
- 插件命令，用于启用/禁用自动存档，以及强制激活或请求自动存档。
- 通过不同的保存样式，更改保存菜单的显示方式。
- 为保存的文件添加描述和图片。

## 全局开关和全局变量

[![SaveCoreGlobals.png](http://www.yanfly.moe/wiki/images/thumb/7/7c/SaveCoreGlobals.png/600px-SaveCoreGlobals.png)](http://www.yanfly.moe/wiki/File:SaveCoreGlobals.png)

全局开关和全局变量现在通过此插件添加到游戏引擎中。全局开关和全局变量在所有存档文件中都处于相同的状态。这意味着，如果将开关 40 声明为全局开关并设置为“开启”，那么无论您是启动新游戏还是打开不同的存档文件，开关 40 都将处于“开启”状态。全局变量的情况也类似。

---

```

<Global> 开关/变量名称

```

要声明全局开关和/或全局变量，请在开关/变量名称中插入 `<Global>`。就是这样。声明全局开关/变量后，无论你将其值更改为什么，所有保存操作都会应用该值。

---

注意：带标签的开关/变量彼此互斥。你不能同时使用 `<Global>`、`<JS>` 或 `<Self>` 标签标记它们。
