# 暂且试着运行一下

学习编程语言时，通常需要先搭建执行环境，但rmmz中已经准备好了。

创建好rmmz项目后，立刻进行测试试玩吧。

打开标题画面后，按下“F8”键。我想会弹出一个与游戏不同的窗口。

这被称为“开发者工具”，对于熟练运用脚本进行游戏开发与调试非常有帮助。

## 输出日志

开发者工具中功能非常之多，但这次请先选择“Console”标签页。

我想会显示如下所示的内容。

![img](https://rpgmakerofficial.com/product/mz/assets/images/lecture/plugin/javascript/zikkou/01-01.png)

在这个白色画面中可以输入文字。

首先试着如下输入吧。

```
console.log('Hello RPG Maker MZ');
```

![img](https://rpgmakerofficial.com/product/mz/assets/images/lecture/plugin/javascript/zikkou/01-02.png)

运行结果应该会如上所示。这样一来，我们成功执行了js并确认结果！

刚才执行的脚本是一条命令，意为“在控制台显示字符串‘Hello RPG Maker MZ’”。

console.log正如其名，是输出日志的命令。

日志是为了确认程序运行状态而输出的，并不会改变游戏的行为。

或许有人会想，与其用这种东西，不如从事件命令的“脚本”中执行各种操作。

但出于以下理由，我不推荐这样做。

- 无法当场确认执行结果
- 没有输入补全（输入中途自动显示候选功能）
- 若语法错误，会发生错误并导致游戏停止

因此，请先在开发者工具中输出日志，同时学习js的基本语法，之后再挑战事件命令。
