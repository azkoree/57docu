# 作为素材发布时的注意事项

如果不是作为游戏作者制作自己专用的插件，而是考虑作为插件素材发布，那么就需要下一些功夫让更多的人使用它。

## 多语言支持

发布插件后，可能会有各种语言圈的用户使用。

因此，通过创建与编辑器语言设置对应的帮助，可以增加被更广泛用户使用的可能性。

要为每种语言创建帮助，请在帮助注释的开头加上语言代码。

例如，日语的情况如下。

```
/*:ja
  * @target MZ
  */
```

中文就是：

```
/*:zh
  * @target MZ
  */
```

如果有语言代码与使用者的语言代码相匹配，就会使用该帮助。

如果没有匹配的，就会使用如下不带语言代码的帮助。

```
/*:
  * @target MZ
  */
```

## 许可证的设置

许可证，说白了就是插件的使用条款。

自己制定使用条款也可以，但由于需要考虑商业利用、R18 作品使用等各种情况，采用已经普及的许可证可以预防包括其他语言圈用户在内的误解和纠纷。

反之，完全没有许可证或使用条款的插件，对使用者来说可能仅仅使用就会触犯著作权法，使用风险会变得很高。

根据许可证的不同，有时需要明示条文或条文的链接，以及需要著作权标注。
