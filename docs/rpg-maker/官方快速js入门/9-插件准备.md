# 制作插件前的准备

本章将提供一些信息，作为运用前一章所学的 js 知识来实际制作插件的第一步。

## 编辑器的安装

插件基本上用 js 编写。

文件是文本格式，因此使用平时使用的记事本或文本编辑器也可以开发，但推荐准备一个专用于 js 开发的专用编辑器。

专用编辑器方面，搜索一下会出现很多比较介绍的的文章，请选择符合自己喜好的编辑器。

文章最好是发布日期较新的。

专用编辑器有以下特点。

- 代码补全（当代码写到一半时，预测并提示后续的写法）
- 通过静态分析显示警告（事先警告可能导致编译或执行错误的写法）
- 格式化工具（根据预先设定的规则自动调整缩进等格式）
- 调试（中途停止脚本执行，确认变量或逐行执行）

插件的制作是复杂而细致的工作，但活用这些编辑器的功能，可以轻松高效地进行。
