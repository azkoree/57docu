# 引言

rmmz中的脚本，是用于访问游戏运行及规格根本部分的手段。

rmmz的游戏部分全部由名为JavaScript（后称js）的语言实现，因此脚本也需遵循js的语法来指定。

熟练运用脚本，可以比仅用事件命令编写事件实现更加高级、高效的游戏开发。

但是，若无法熟练运用，反而会降低可维护性，甚至可能陷入无法控制自己游戏的危险。

## 本章的目的

本文面向js零基础者，专门针对rmmz，讲解必要最低限的js知识与语法。

最终目标是为了能熟练运用事件命令中的“脚本”。

为了以最短路径达成目标，有时会省略详细说明或不够严谨，敬请谅解。

不要求有编程语言经验，但希望您已掌握rmmz的基本规格和事件的编写方法。

### 关于JavaScript

js原本是以在Web浏览器中运行为前提的编程语言。近年来随着Node.js的出现，被广泛用于包括服务器端在内的各种领域。

因此虽然相关的教程网站和书籍很丰富，但由于执行环境和语法因用途而异，直接照搬网站等信息到rmmz中可能无法运行。

因此，如果为了在rmmz中熟练运用脚本而去寻找普通的书籍或网站，反而可能绕远路，请务必注意。

:::note

**js与Java无关**

有一种名为“Java”的、主要在服务器端广泛使用的编程语言，但它与js无关。

因为名字相似，购买书籍或进行网络搜索时请勿弄错。

:::
