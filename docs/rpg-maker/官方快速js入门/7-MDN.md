# 关于 MDN Web Docs

到此为止，我们快速讲解了 js 的基本语法。

但这当然不是 js 的全部。

如果想了解 js 的规格和来历，推荐 MDN Web Docs（Mozilla Developer Network）。

这里全面收录了包括 js 在内的 Web 开发技术的规格和技术信息。

[MDN Web Docs](https://developer.mozilla.org/ja/docs/Web/JavaScript)

当然，它并非专门针对 rmmz，所以并非所有信息都有用。

但是，当你在学习 js 遇到困难时，搜索这里一定能获得解决问题所需的线索。

（当然对于国内来说肯定还有其他的网站，就凭自己喜好去找了）
