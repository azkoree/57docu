## Rearrange

1. 上传您的精灵图。
2. 设置网格：从下拉菜单中选择预设尺寸，或输入自定义帧尺寸（宽度 x 高度，单位为像素），然后点击“分割”。或者，输入列数/行数，然后点击“自动网格”自动计算帧尺寸。
3. 使用每行旁边的箭头向上/向下移动行（或使用列旁边的箭头移动列）。
4. 或者，点击一行/一列（蓝色高亮显示），使用箭头键进行导航。按住 Ctrl 键并点击可切换单个选择（添加/移除）。按住 Shift 键并点击可选择一个范围。拖动可交换或移动（使用“拖动：交换/移动”按钮设置默认操作）。按住 Ctrl 键并拖动可执行与默认操作相反的操作。按住 Ctrl 键并使用箭头键预览移动，然后释放 Ctrl 键应用更改。按 Esc 键取消。
5. 在“行”、“列”或“帧”模式之间切换，以控制您要重新排列的内容。
6. 在“帧”模式下，您可以进行多选：按住 Ctrl 键并点击可切换单个帧（从选择中添加/移除），按住 Shift 键并点击可选择一个范围，按住 Shift 键并拖动可绘制选择框。使用箭头键进行导航，按住 Shift 键并使用箭头键扩展选择范围。拖动选定的帧以交换它们。按住 Ctrl 键并使用箭头键预览（绿色轮廓），然后释放 Ctrl 键应用更改。目标位置的帧将交换回来。删除键可清除选定的帧。（注意：“移动”功能在“帧”模式下禁用 - 仅“交换”功能可用。）
7. 使用缩放控件调整视图。点击“弹出”按钮可打开全屏编辑模式，用于处理较大的精灵图。使用“撤消”按钮可恢复更改。
8. 使用“+ 行/列”按钮扩展您的精灵图。使用“删除”按钮删除当前选定的行/列/帧。
9. 使用“批量添加”功能一次添加多个精灵图（选择多个文件，然后点击“右侧”或“底部”）。
10. “动画预览”面板显示您的精灵图动画。使用“开始帧/结束帧”导出特定部分的 GIF 动画。比例（x2、x3 等）下拉框用于设置导出动画的大小。
11. 使用“预设”功能保存/加载您的作品。
12. 使用“移动到网格调整器”功能将您的精灵图传输到“网格调整器”选项卡以调整帧大小。
13. 完成后，下载为 PNG 格式！ 

## Resize
1. 加载精灵图图像（推荐使用 PNG 格式）
2. 设置源网格 - 每个精灵帧的当前尺寸（例如，32x32），或者使用自动网格功能根据列数/行数计算。使用预设下拉菜单选择常用尺寸。
3. 设置目标网格 - 每个帧所需的尺寸（例如，96x96）。使用比例功能按比例缩放（例如，3/4 = 75%，非常适合非正方形精灵）。
4. 选择精灵位置锚点：确定精灵在每个新帧中的位置。底部居中非常适合角色精灵（脚部保持对齐）。
5. 选择缩放模式：不缩放保持原始尺寸，缩放到合适尺寸会将精灵放大/缩小以适应帧，缩放到填充尺寸会将精灵缩放到填满整个帧。
6. 使用偏移量 (X/Y) 通过在锚点位置添加/减去像素来微调精灵位置。
7. 点击“转换”生成调整大小后的精灵图！
8. 使用批量添加功能在转换前合并多个精灵图（选择文件，然后点击“右侧”或“底部”）
9. 下载结果，或使用“移动到重新排列器”功能在“重新排列器”选项卡中继续编辑

提示：使用预设功能选择常见的 RPG Maker 格式。该工具将自动根据您的图像计算行数/列数。
